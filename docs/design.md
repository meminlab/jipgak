# 집각 디자인 기준 v1 (2026-11-19)

디자인(BANB-63) 시안 v1 기준입니다(클라이언트 승인 2026-11-27). 토큰 값은 시안 목업(`jipgak-mvp-mockup.html`, BANB-63 첨부)의 `:root` 변수와 같고, 코드에서는 `src/index.css`의 CSS 변수로 씁니다. 바꿀 때는 디자인이 이슈에 변경안을 올리고 개발이 PR로 반영합니다.

## 원칙
- 숫자가 주인공입니다. 금액은 크게, 단위와 설명은 작고 흐리게 씁니다.
- 색은 판단에만 씁니다. 초록 = 살 각(예산 안·여유·적용값), 주황 = 부족, 빨강/파랑 = 가격 상승/하락(국내 관례).
- 한 화면에 강조는 하나만 둡니다(상세 = 필요 자금, 목록 = 필요 자금 구간).
- 문구는 "~해요" 체로, 왜 안 되는지와 다음 행동을 같이 씁니다.

## 간격·라운드·그림자
- 간격 4 단위: 4 / 8 / 12 / 16 / 20 / 24 / 32. 화면 좌우 여백 16, 카드 안 16, 카드 사이 10~12.
- 라운드: 입력·칩 8, 카드 12, 바텀시트 20, 알약형 999.
- 그림자: 카드 `0 1px 2px rgba(20,24,28,.06) + 1px 테두리 4%`, 떠 있는 요소(검색·마커·FAB) `0 4px 14px rgba(20,24,28,.14)`, 시트 `0 -6px 20px rgba(20,24,28,.10)`.
- 터치 영역 최소 40×40, 주요 버튼 높이 52.

## 아이콘 — Lucide 1종만(혼용 금지), 20px / stroke 1.75, 작은 곳 16px
- 탭: `map` 지도 / `star` 내 단지 / `sliders-horizontal` 내 조건. 스크랩은 `star`(채움 #FFC53D).

## 금액·숫자 표기
- 기본: 억·만원 — `7억 3,500만`, `8,500만`, `5억`(만 단위 0이면 생략). "원"은 입력 필드 단위에만.
- 지도 마커만 축약: `8.7억`(소수 1자리, 1억 미만은 `8,500만`). 공간 때문입니다.
- 변동률: 소수 1자리 + 부호 `−14.7%`. 날짜: 목록·표 `2026.10.24`, 기준일 문구 `2026-10-16`(명세 문구 그대로).
- 면적: `전용 84㎡ · 공급 112㎡`, 평형 `34평`(공급 기준). 공급 없으면 `전용 102㎡(31평)` + "공급 미확인".

## 컴포넌트
- 버튼: primary(초록) / secondary(회색 면) / small(36). 화면당 primary 1개.
- 입력: 높이 48, 값은 오른쪽 정렬, 단위는 회색. 포커스 = 초록 테두리 + 3px 연한 링. 금액 입력 아래에 억/만 환산을 보여줍니다.
- 세그먼트: 주택 수·금융권·상환방식. 토글: 생애최초·이사비·예산 안만.
- 칩: 정렬(선택 = 검정), 필터("내 예산 안" ON = 초록).
- 지도 마커: 말풍선형, 1줄 가격 + 1줄 평형. 예산 안 = 초록 채움, 예산 밖 = 흰색 55% 투명, 선택 = 검정 테두리 + 확대, 스크랩 = 노란 별 배지. 클러스터 = 원 + 개수 + "예산 안 N".
- 바텀시트: 지도에서 마커를 누르면 요약(단지·연식·최근가·필요 자금·부족/여유) → 위로 끌거나 누르면 상세.
- 대출 2칸: LTV | DSR 나란히, 실제 적용되는 작은 값 칸에 초록 테두리 + "적용" 배지.
- 상태 배지: 집계 중(warn) / 해제·직거래·거래 없음(gray) / 살 각(brand) / 부족(short).
- 안내 문구 박스: 회색 면 + info 아이콘, 모든 계산 결과 바로 아래.
- 빈 상태: 원형 아이콘 48 + 제목 15/700 + 설명 13 + (있으면) 행동 버튼 1개.
